# Weekly Review: close loops, do not produce vibes

A review that changes nothing is a diary. This one reconciles commitments
against outcomes and leaves next week a small, checkable set.

## Rules

1. **Pull commitments from the last log, not from memory.** Memory keeps
   the wins and rewrites the misses; the log is the contract.
2. **Evidence or it is not done.** Every completion claim names its
   evidence — shipped, sent, merged, filed. "Made progress" is a feeling,
   not a state.
3. **Bank wins as evidence.** Completed work is recorded concretely, in the
   form that pays off later at review, retro, or performance time.
4. **Carry forward with a fresh reason.** Unfinished items continue only
   with a stated reason to continue now; an item carried silently is a
   dropped item wearing a costume. Dropping explicitly is allowed and
   recorded.
5. **Commit small and checkable.** Next week holds a few specific
   commitments; a fifteen-item list is next week's failure, pre-written.
6. **Log the review.** One dated entry per review in one file, so the next
   review starts with a read and drift becomes visible across weeks.

## Steps

1. **Locate the log.** Find or create the review file; read the latest
   entry's commitments. Done when: last week's commitments are quoted from
   the log, not remembered.
2. **Reconcile.** Mark each commitment done / partial / not-done, evidence
   attached. Done when: every commitment has a state and every done has
   evidence.
3. **Carry or drop.** For each unfinished item: a fresh reason to continue,
   or an explicit drop with a reason. Done when: no item carries over
   silently.
4. **Commit next week.** Write the small, checkable set — each item
   completable and verifiable within the week. Done when: the set is few
   enough to fit a real week and each item names its done condition.
5. **Write the log.** Append the dated entry: reconciliation, banked wins,
   carry-forward list, next-week commitments. Done when: next week's
   step 1 could run from this entry alone.

## Done when

Every commitment from last week has a state with evidence, unfinished work
carries a fresh reason or an explicit drop, next week holds a small
checkable set, and the dated log entry exists for next week to compare
against.
